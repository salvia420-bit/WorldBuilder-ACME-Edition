The 1999 pack,
at endgame scale.

The client faithfully rebuilt Asheron's Call's retail inventory — paperdoll, eight brass bag-tabs, 32×32 icons. It's authentic, and it's a 800×600 spatial UI asked to manage a stash that stacks a thousand to a slot. Here's how to keep the mood and still find your recall gem — on a controller, a phone, or a mouse.

The real problem

Retail managed slots. Endgame is about sets.

A 275-slot spatial grid answers "which slot is it in?" — a question nobody wants to ask 40 times a day. The AC community never fixed the window; they bolted a query layer on top with Decal (MagTools, Virindi). That layer is the actual feature. holtburger has the authentic window; it's missing the thing everyone actually ran.

What we have

Spatial slot management

  • Eight tabs, 32×32 icons, eyeball-scan to find anything
  • Drag-drop is the only verb — dead on pad & touch
  • Comps re-slotted into the belt by hand after every buy
  • "Sell the junk" = 60 individual right-clicks
What players built

A query layer, bolted on

  • Search by name; filter presets (unequipped, untinkered, loot-rule)
  • Sort by value / burden / stack; where-is-it item logs
  • Bulk select → sell / salvage / move as one action
  • Auto-restocking comp slots that never run dry

"presets to filter your inventory — only show non-equipped, non-tinkered, matches a specific loot rule…"  ·  "the MagTools inventory logs, so I could search items and report where they are, offline." — AC tool-dev community (Chorizite / sourcecode archives)

The cross-input spine

One primitive survives all three: Focus → Confirm → List.

Drag-drop can't be the backbone — it dies on a thumbstick and fights a touchscreen. But point at a thing, press to use it, open a vertical menu for everything else maps cleanly onto every input. And it's not a compromise: retail's "radial" menu was already a vertical list (it's in the client comments). No wheels — anywhere. Drag stays as a mouse-only accelerator, never a requirement.

Seven moves

Modern behavior under a retail skin.

01

Two lenses, one bag

Packs = today's diegetic paperdoll & tabs, untouched, for immersion and "where physically is it." Ledger = a query view over the exact same items: search, category, sort. One toggle flips the lens.

→ immersion AND scale, no trade

02

Stack-as-unit

A 1000-taper stack is one card with a big count, not a thing to babysit. Split/merge with a stepper — "Take 50 / Half / All" — never drag-math. Comps stop being inventory; they're just a number that draws down.

→ ×1000 stacks become trivial

03

Self-filling belt

Bind a category ("Healing Comp", "Bread"), not a slot. The belt always fires your deepest matching stack and never empties while you carry the type. The end-game comp-reslotting chore just… ends.

→ kills the after-every-buy ritual

04

Saved smart-views

"Unequipped & untinkered." "Comps under 200 value." "Sellable junk." "Salvage bait." The community's Decal presets, native and one tap away — and they feed bulk actions.

→ MagTools, built in

05

Multi-select + bulk

Select-mode → apply a filter → Sell all / Salvage all / Move to Pack 3 / Split evenly. Turns "ten thousand items" from a browsing problem into a set operation. A checkbox toggles on tap or A.

→ 60 right-clicks → 1 action

06

Context-adaptive pane

The same window changes its verb by situation: vendor → Sell, corpse → Loot-all, forge → Salvage, trade → Offer. You never navigate to the action; the world hands it to you. Extends the existing one-pane-many-views panel.

→ the right verb, already surfaced

07

Type-to-find bar

The keyboard power-move: F, type "recall", enter. Muscle-memory from Decal, native. Degrades gracefully — on pad/touch the same bar becomes category chips + a Recents row instead of a keyboard.

→ instant on KB&M, graceful elsewhere

Keeping the mood

Immersion is a skin, not a constraint.

None of this needs a flat Material-Design panel. Modern behavior, retail materials — the search box is brass, the chips are worn vellum, the paperdoll stays sacred.

Diegetic naming

It's a Ledger or Satchel Index, not a "database view." Searching is your character sorting the pack — dressed as fiction, not a spreadsheet.

Material language

Every new surface uses AC's own kit: 9-slice brass frames, stone/leather grounds, the serif face, the gold text. Nothing reads as a web widget.

Purist opt-out

The Ledger, belt, and filters are a layer. Fits the project's default-on-with-escape-hatch culture — run Packs-only if you want 1999 exactly. ?ledger=off.

No wheels, ever

Context = a list. Belt = a strip. Filters = chips. The one pattern players actively dislike is the one pattern we never use.

Where I'd push — your call

Open questions before any of this is a plan.

How far past "sort buttons"?

A community dev literally added sort/search buttons to the retail window. Is that lighter bolt-on enough — or is the full second-lens Ledger worth the build? My lean: build the spine (Focus→Confirm→List + stack-as-unit) first; it pays off even Packs-only.

Bulk ops vs. server authority.

"Sell all junk" is a burst of packets. Needs client-side optimistic + throttle — you already have optimistic audio/drop plumbing to model it on. Worth checking ACE's rate limits before promising one-tap bulk.

Do same-name stacks collapse?

Two identically-named-but-differently-tinkered items in the Ledger: one card or two? Affects whether the query layer is a pure view or needs per-item identity surfaced. Retail kept them separate; the Ledger tempts merging.

Controller belt shape.

Four d-pad slots (always live, muscle-memory) vs. a hold-bumper scrollable strip (N slots, one more input). Comps want breadth; combat wants zero-latency. Possibly both — d-pad for the four you fight with, strip for the long tail.
