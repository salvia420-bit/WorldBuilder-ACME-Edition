## What changed
`parseDescriptorsJsonl` is now a **strict superset** of the prior parser:
- component id read from `string | {id} | {name}` (the live classifier emits `{name}` — the bug).
- per-component **nested `config`** hoisted to `config[id]`; a top-level `config{}` (the canonical
  future-emit shape) wins on collision. `_splitConfig` (`frag_attach.js:44`) buckets the object-valued
  keys into `byId[componentId]`, so config now reaches every component.
- a leading **UTF-8 BOM** stripped (the C# emit writes one; `res.text()` strips it, a raw node read does not).
- `sidecars{}` + `schemaVersion` recorded (for the P4 bake-migration).
