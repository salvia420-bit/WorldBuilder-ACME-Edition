## Key facts / gotchas (hard-won)

- **Harness import gotcha:** the source-eval headless harness does NOT resolve ESM
  imports. A module-LOAD call to an imported fn ReferenceErrors (broke
  `test_a5_p3_root_motion` until fixed). Read flags via `URLSearchParams` INLINE
  (like `FULL_BODY_ONE_SHOT`), not via an imported helper. Imported fns used only in
  runtime branches are inert when the flag is off.
- **Can't verify render here:** local Playwright + swiftshader crashes ("Target
  crashed") on the FIRST evaluate after in-world on the 2nd+ run (1.6G /dev/shm, 8GB
  box). First cold run is the most reliable; `--disable-dev-shm-usage` helps. See
  memory `reference_local_inworld_hud_verify`.
- **Wasm builds:** ALWAYS `capped-build` (OOM jail) — never a raw workspace build.
  `cargo check --target wasm32` from the web dir is the fast validate (~27s).
- **Wide multi-agent on the buildbox:** the audit ran 18 `claude -p` Opus agents on
  the buildbox (Max OAuth headless works), pushed to a branch, self-stopped. Reusable
  pattern + driver: memory `reference_buildbox_headless_claude_workflow`,
  `/mnt/wbterminal1/tmp/claude-scratch/bandb-verify/anim-audit-driver.sh`.
- **The wasm boundary is FAITHFUL — do NOT touch it.** `EntityAnimationData`
  (src/lib.rs:15510) ships per-part absolute model-space keyframes + per-frame times
  + root motion + hooks; the rig is FLAT (`part_${p}` children of root). Building a
  bone hierarchy would double-apply (audit part 12).
